# Hojas de vida de prueba

Pon en `muestras/cvs/` las hojas de vida que quieras usar en la demo. Esa carpeta no se versiona (está en `.gitignore`), así que nunca sube CVs al repo.

Para no usar datos reales, puedes tomarlas del dataset público [Resume Data PDF](https://www.kaggle.com/datasets/hadikp/resume-data-pdf) en Kaggle, que trae hojas de vida de ejemplo en PDF organizadas por área.

Formatos aceptados: PDF, DOCX, JPG, PNG y TIFF, en español o en inglés.
